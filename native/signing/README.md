# مفتاح توقيع نسخة أندرويد

`asfari-release.p12.enc` هو مفتاح توقيع ملف APK، **مشفّر** (AES-256، ‏PBKDF2 بـ 600 ألف تكرار).
لا يُفتح إلا بكلمة السر المحفوظة في خزنة GitHub السرية باسم `SIGNING_PASSPHRASE`
(Settings ← Secrets and variables ← Actions)، فلا يستطيع أحد غيرك أن يوقّع نسخة تُثبَّت فوق تطبيقك.

- أندرويد لا يقبل تحديث التطبيق إلا بالمفتاح نفسه، فلا تحذف هذا الملف ولا تغيّر كلمة السر.
- احتفظ بكلمة السر في مكان آمن خارج GitHub أيضاً (مدير كلمات المرور مثلاً).
- لا تضع أي مفتاح أو كلمة سر غير مشفّرين في المستودع.
